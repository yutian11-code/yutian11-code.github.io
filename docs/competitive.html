  • 用途：给决策者（大哥）的弹药库 —— 只看被市场验证成功过、且吸引人的功能，并据此设计 MMU 第一炮的 5 个功能

一、三条铁律（27 个 App 跨赛道调研，结论高度一致）

  1. "AI 出一张以用户本人为主角的可分享卡片" = 被反复验证的冷启动核弹。 妙鸭 18 天冲 App Store 下载榜第一、单日收入 55 万元；Lensa 上线 5 天收入 820 万美元；Remini 登顶 App Store（超过 Threads）；个人色彩 #coloranalysis 播放 7.5 亿次；新氧魔镜测脸累计用了 2.5 亿次。这条路完全跑得通。

  2. 纯一次性卡片必死 —— 留存是生死线。 妙鸭日活从 60 万跌到 3.6 万、收入跌 92%、团队解散；Lensa/ZAO 一夜断崖；Dressika 只能靠 TikTok 不停灌新用户续命。第一天就要解决"为什么回来"。

  3. "不带化妆台/录入"的判断是对的 —— 不只是因为没库，是这模式本身留存差。 化妆台/保质期/录入被独立验证为"录入劝退 × 低频 = 留存陷阱"：BeautiStics 上线多年仅 25 条评价；微信侧根本没跑出量级的个人化妆台小程序。

三、功能菜单（按"拉新 / 留存 / 变现"，标注验证 + 吃库）

拉新钩子（出可分享卡片，全部 ❌ 不吃库）

  • 测脸/测肤评分报告卡 —— 新氧 2.5 亿次、你今天真好看 1000 万+下载
  • 个人色彩/季型身份卡 —— 全球 7.5 亿播放、Dressika 650 万下载、中国小程序空位
  • AI 妆容"拍同款"模板卡 —— 轻颜日均 60 分钟+
  • 戏剧化反差产出（素人→定制妆效前后对比）—— FaceApp 4.8 亿下载

留存机制（几乎不吃库）

  • 趋势记录 / 定期复测 —— 你今天真好看趋势曲线
  • 游戏化挑战 + 进度条 / 打卡 —— Sephora 挑战 +47%、Ulta 进度条
  • 诊断当入口 → 后接内容/推荐/社区 —— Zamface 350 万用户
  • 工具型内容 + 搜索 —— 小红书 MAU 3.5 亿

变现（早期轻，重的留到有体量）

  • 美妆导购佣金（卡片接产品种草）—— 测肤用户转化 3–5 倍（NielsenIQ×美图）
  • 一次性/轻付费解锁深度报告 —— 个人色彩 $4.49–40
  • ⚠️ 真实品牌色号 AR 库 / B2B SaaS —— Perfect 89 万 SKU，冷启动别碰
  • ⚠️ 自营电商 / 自营 SKU —— 2024–26 多家下滑，红海

四、五大功能设计（被验证 + 吸引人 + 不吃库；合起来是一条闭环）

选取标准：① 有成功 App 用真金白银验证过；② 自带社交货币/吸引力；③ 不吃产品库（或仅需手工种子清单）；④ 第一版能用"手工出卡"快速验证。 闭环关系：①获客 → ②裂变 → ③④回流留存 → ⑤变现 → 绕回获客。

功能 ① 个人色彩季型卡（获客主钩子）

  • 是什么：4–6 道选择题（肤色/发色/瞳色/血管色）± 可选自拍 → 出"冷冬型/暖秋型"身份大标签 + 专属色卡（适合的口红/粉底/穿搭色），渲染成一张可保存可晒的卡片。
  • 谁验证过：#coloranalysis 7.5 亿播放；Dressika 650 万下载、月流水约 13 万美元；Zamface 350 万用户；线下个人色彩 19.9 元~数千元、SHISPACE 半年卖 1000+ 套≈138 万元。且中国微信小程序无独立爆款 = 空位。
  • 为什么吸引人："我是冷冬型" = 美妆界 MBTI，强身份标签，极想晒、想拉姐妹来测；是事实性自我认知（比巴纳姆"被看穿"更硬、更经得起复测）。
  • 吃库：❌（色卡是"色号原型"，非真实 SKU）。
  • 角色 / 验证成本：拉新主钩子 / 纯答题，L0 手工出卡即可测，零开发起步。

功能 ② "只有 X%" 稀缺感 + 一键晒卡海报（分享放大器）

  • 是什么：卡片标注"全网只有 8% 的人是冷冬型"（后台按历史命中分布实时算）；一键生成竖版海报（卡片 + 小程序码 + 引导文案），存图发朋友圈/小红书。
  • 谁验证过：妙鸭/Lensa 靠"出卡即晒"裂变（妙鸭单日 55 万收入）；新氧颜值卡 2.5 亿次；朋友圈无法直发小程序 → 存图是主路径（妆签 MVP 已认知）。
  • 为什么吸引人：稀缺 = 炫耀 + FOMO（"全网都在玩"）；产出天然适配信息流，别人看了也想测 = 裂变闭环。
  • 吃库：❌。
  • 角色 / 验证成本：拉新裂变 / L1 可手工配海报。

功能 ③ 换季复测 /「另一面的你」（留存核心）

  • 是什么：给已测用户"换季了，你的色卡该更新了"提醒 + 解锁"另一组风格/隐藏型"复测；「我的色卡」常驻入口随时翻。
  • 谁验证过：你今天真好看靠肤质趋势曲线做留存；个人色彩行业通用"季节 lookbook + 可重测"；Zamface 把诊断接成日常美妆起点。反证：妙鸭无复测 → 月活月抛。
  • 为什么吸引人：回来能解锁新身份 + 看自己变化；把"一次性测试"变成"定期回来的动作"。
  • 吃库：❌。
  • 角色：留存（直接给"为什么回来"的答案）。

功能 ④ 每周话题挑战 + 晒卡打卡（留存 + 裂变双引擎）

  • 是什么：运营每周推"本周话题卡"（如 #氛围感妆 / #新年红），用户出卡参与 + 打卡，连续天数/进度可视化。
  • 谁验证过：Sephora Beauty Insider 挑战让参与度 +47%；Ulta 积分进度条占营收 95%；FaceApp 变老挑战 / Remini 婴儿照 → 统一玩法让 UGC 在小红书自堆量。
  • 为什么吸引人：统一话题降低创作门槛 + 蹭节点热度；进度条/连续打卡的完成欲；比投放便宜得多的自然裂变。
  • 吃库：❌。
  • 角色：留存 + 拉新。

功能 ⑤ 色号 → 精选选品清单 + 导购（轻变现桥）

  • 是什么：每个推荐色号下挂 3–5 支精选代表产品（手工种子清单，先平替款后升级款）+ 导购链接；"你的冷冬型适合这几支正红"。
  • 谁验证过：NielsenIQ×美图——测肤用户产品留存 2 倍、转化 3–5 倍；Zamface/小红书"诊断 → 导购"成熟；个人色彩天然落位美妆导购。
  • 为什么吸引人："知道自己适合买什么、不踩雷"的事实性价值；从身份认知顺滑到购物决策。
  • 吃库：🟡 轻 —— 只需手工精选种子清单（每色号 3–5 支），不是全量 SKU 库，正好用"种子库 + 电商联盟库"平替。
  • 角色：变现（等有日活后再接）。

五、对 MMU 的结论

  • 拉新和留存的所有高价值功能（评分卡/季型卡/趋势/挑战）全都不吃 SKU 库 —— 库是后期变现护城河，不是冷启动门票。
  • 核心产出就是"一张卡"，能纯手工（人 + LLM）造出来先测 —— 第一炮零库、零引擎、几乎零开发。
  • 用"换季复测 + 周更挑战 + 诊断接后端"接住留存，避开妙鸭"月活月抛"。
  • 第一炮最优解：个人色彩/季型卡（功能 ①），其余 4 个功能围绕它形成闭环；先 L0/L1 手工验证"卡招不招人"，跑通再做真小程序谈留存。

附：数据说明

速度优先，单点数字（尤其 MAU/下载量/月流水）多为媒体披露或第三方（Sensor Tower / Similarweb）估算，作量级参考；正式立项前对关键数字再核一遍。各条均附出处于子调研报告中。
